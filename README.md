# Workflow Demo

Projeto de demonstração de workflow com Git e GitHub.

## 📋 Sobre

Este repositório foi criado para praticar e demonstrar fluxos de trabalho com Git, incluindo:

- Criação e gerenciamento de branches
- Commits e versionamento
- Merge e resolução de conflitos
- Boas práticas de desenvolvimento

## 🚀 Como usar

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/workflow-demo.git

# Entre na pasta
cd workflow-demo

# Crie uma nova branch
git checkout -b minha-feature

# Faça suas alterações e commit
git add .
git commit -m "Descrição das alterações"

# Envie para o repositório
git push origin minha-feature
